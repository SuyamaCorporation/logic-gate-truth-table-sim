# Logic Gate Truth Table Simulator

## 概要
AND/OR/NOT/XOR/NAND/NOR/XNORの7種類の論理ゲートを選択し、入力数（1〜3変数）を設定すると真理値表と論理式を自動生成する教育ツール。

## 機能
- 7種類の論理ゲート選択（AND/OR/NOT/XOR/NAND/NOR/XNOR）
- 入力変数数の選択（1〜3変数）
- 真理値表の自動生成（出力1の行を緑でハイライト）
- 論理ゲートの図解（canvas描画）
- ブール代数式の表示
- ゲートの説明文

## 使い方
ドロップダウンでゲートの種類と入力数を選択すると、真理値表が自動生成されます。NOTゲートを選ぶと入力数は自動的に1に制限されます。
